# Beycord

SunSOG began this bot as a hobby to learn programming languages and better his English.
It was doing pretty well, but unfortunately came to an end on April 1st, 2021.
Now, it has been revived as an open-source project — everyone is welcome to contribute!

## Archived Versions & Forks

Check out their branches to view each codebase:

- **Beycord Original** — Original Repository by SunSOG
- **Beycord Packaged** - Original Repo with missing stuff by SunSOG
- **Beycord V13** - Discord JS v13 Update (The Git Tree for above is [here](https://github.com/thororen1234/beycord-source)) by SunSOG & CorruptX
- **Beycord+** - More Accurate to the original Beycord but way messier by WhizzieGaming
- **NeoBlade** - A Mash up of Beycord+, Beycord, and Beycord Rewrite with extra beys and features by me
